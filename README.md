# SDG 4: Student Performance Predictor

## 📌 Problem Statement
This project addresses **UN SDG 4: Quality Education** by using machine learning to predict student math performance.

## 🚀 Solution
I built a Linear Regression model that analyzes student background data to forecast math scores.

## 📊 Results
- **Model Used:** Linear Regression (Scikit-Learn)
- **Accuracy:** R² Score of **0.88**
